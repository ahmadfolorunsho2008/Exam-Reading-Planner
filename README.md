Exam Reading Planner
A small tool that helps students plan exam preparation by tracking topics to study for each course, how many hours each topic needs, and whether it has been covered.
Right now it is plain JavaScript that filters pending topics, lists topic names, and calculates the total study hours left. Next, I plan to turn it into a deployed, database-backed API with user login, so students can save their own reading plans and track progress across courses.
Run it with node app.js.
